# Волна 5 «Друзья и Лидеры» (v1.0): спецификация

Макет: `design/волна-5/макет-друзья.html` (открыть в браузере; `?f=15` — один кадр). Кадры 01–42: `design/волна-5/кадры-друзья/`.
Решения архитектора — `design/волна-5/решения.md`, **с поправкой владельца: друзья настоящие, онлайн, на своём сервере** (пробных друзей и плашки «это пример» нет). Магазин, задания, профиль и набор аватаров — у второго дизайнера (`спец-магазин.md`).

## 0. Коротко

- **Аккаунт — по желанию.** Без аккаунта приложение работает как сейчас; «Друзья» и «Лидеры» показывают «Войди, чтобы дружить». Аккаунт = **@ник + пароль**, без почты и телефона. Ник проверяется на лету («свободен / занят + три свободных варианта»).
- **Друзья** — список с поиском по @нику, заявками, «тебя подбодрили». Строка друга: аватар, имя, лучшая серия, сколько деревьев растёт, полил ли сегодня (капля / галочка), отметка «подбодрил».
- **Найти друга** — поиск по @нику с 3 знаков; «Добавить» → заявка. **Заявки** — входящие (принять / отклонить), исходящие (отменить). **Позвать** — системное «Поделиться» со ссылкой-приглашением.
- **Профиль друга** — мини-лес в шапке, имя и @ник, три числа, тёплая кнопка «Подбодрить» (раз в день, ладошки летят к аватару), общее дерево, открытые деревья, «ещё N скрыто». Меню «⋯»: общее дерево, **Пожаловаться, Заблокировать, Убрать из друзей**.
- **Лес друга** — тот же экран «Мой лес» в режиме «только посмотреть»: без перестановки и правок, в карточке дерева «Посмотреть» и «Подбодрить».
- **Общее дерево** — предлагаешь другу (привычка, делаем / не делаем, вид дерева) → друг принимает → у обоих появляется **отдельное дерево на главном экране** с двумя половинками аватара. Растёт только в день, когда полили оба; общие шансы по обычным правилам.
- **Лидеры** — «Неделя» / «Лучшая серия», пьедестал + список, ничьи делят место, считаются только деревья, открытые друзьям. Только «я + друзья».
- **Сеть** — моё всегда работает без интернета; данные друзей хранятся в телефоне со временем «на когда». Состояния: загрузка (скелетоны), нет интернета (таблетка «данные на 14:05»), ошибка («Повторить»), устаревшие данные друга («обновлено 6 ч назад»), действия в очереди.
- **Приватность**: на сервер уходят только деревья с пометкой «Друзья». Скрытые не покидают телефон (на сервер идёт только их количество для «ещё 1 скрыто»).
- Живых холстов Skia: «Друзья», профиль, лидеры, поиск — **ноль** (деревья — снимки); общее дерево и лес друга — как свои экраны (1 / по правилам леса).

## 3. Аккаунт: создать, войти, без аккаунта (кадры 01–04, 40)

### 3.1 Когда показываем
1. **Первый запуск версии 1.0** (и у новых, и у обновившихся) — один раз, полноэкранно, поверх главного: «Создай аккаунт». В шапке справа «Позже» → закрыть, больше сам не появляется.
2. Плитки меню «Друзья» и «Лидеры» без аккаунта открывают экран «Войди, чтобы дружить» (кадр 01).
3. Настройки → группа «Аккаунт» → «Войти или создать аккаунт».
4. Сессия истекла (сервер ответил «не авторизован») — экран входа с подставленным ником и заголовком «Войди снова».

### 3.4 Правила ника и проверка на лету (`game/nick.ts`)
- Вводимое сразу приводится: заглавные → строчные, «@» в начале убирается, пробел → `_`, остальные недопустимые символы не вводятся.
- Можно: `a–z`, `0–9`, `_`. Длина 3–20. Начинается с буквы. Нет `__` подряд и `_` в конце. Не из списка зарезервированных (`admin`, `support`, `help`, `moderator`, `official`, `system`, `root`, `null`, `elevate`, `tree`, `derevo`, `mas` и подобные — список на сервере).
- Состояния строки под полем и значка справа:

| Состояние | Когда | Значок | Текст (цвет) |
|---|---|---|---|
| подсказка | пусто | — | «3–20 знаков: латиница, цифры и _» (`textSoft`) |
| неверно | нарушено правило (сразу, без сервера) | — | что именно: «Слишком короткий — нужно от 3 знаков» / «Начни с буквы» / «Этот ник нельзя взять» (`dangerText`) |
| проверяем | 400 мс после последней буквы, запрос на сервере | вращающееся кольцо 22 (`accent` по `sunken`, оборот 800 мс линейно) | «Проверяем…» (`textSoft`) |
| свободен | сервер: свободен | глиф `check` 24, появляется пружиной `pop` | «@sasha_t свободен» (`doneInk`) |
| занят | сервер: занят | красный круг 24 с белым `close` | «Этот ник занят. Свободные:» + три фишки 34 (`sunken`, 14/800) с вариантами от сервера; тап по фишке подставляет ник (`cue('select')`), проверка заново (`dangerText`) |
| нет сети | запрос не прошёл | `wifiOff` 20 `textSoft` | «Проверим, когда появится интернет» — кнопка недоступна |

- Рамка поля: фокус — `accent`; «занят» или «неверно» — `dangerText`.
- Окончательная проверка — на сервере при создании (если за секунду ник заняли — то же «занят» с вариантами).

- Прилипло к низу: L «Войти» и текстовая «Нет аккаунта — **создать**».

- После входа — то же, что 3.5 (тост «С возвращением, @sasha_t!»). Если на сервере уже есть деревья этого аккаунта, а в телефоне другие — **телефон главный**: открытые деревья телефона отправляются на сервер и заменяют серверные (друзья увидят то, что в телефоне). ### 8.7 Правила (`game/shared.ts`) и окончание
- День засчитан, если **оба полили в этот календарный день**, каждый по своим часам (дата `YYYY-MM-DD`). Шансы — общие, 3; пропуск без шансов — гибель; 1-го числа +1 (те же `settle` / `checkIn` из `tree.ts`: дерево с `checkins` = даты, где есть оба).

Дерево уходит с главного экрана, в лесу у обоих — память с табличкой «Вместе N дн.». Новое — только новым приглашением.

## 11. Сеть: загрузка, нет интернета, ошибки (кадры 12–14, 22)

### 11.1 Принцип
- **Своё — всегда в телефоне.** Полив, посадка, лес работают без сети, как раньше.
- **Данные друзей — кэш** (AsyncStorage) с `fetchedAt`. Экран сразу показывает кэш, обновление — в фоне: при открытии «Друзей», «Лидеров», профиля (если `fetchedAt` старше 60 с), при возвращении приложения из фона (не чаще раза в 5 мин), потянув вниз.
- **Действия — в очередь** (`net/queue.ts`): подбодрить, полить половину общего дерева, жалоба, отправка своих деревьев. Повтор при появлении сети (`@react-native-community/netinfo` или `expo-network`) и при каждом запуске; порядок сохраняется; дубли отсекает сервер по id действия.
- Поиск, «Добавить», «Принять», создание аккаунта и вход — **только онлайн** (без сети кнопки недоступны с подписью «Нужен интернет»).

## 12. Данные и сервер (для архитектора)

### 12.1 Что нужно приложению (сущности, а не адреса)
- **Аккаунт**: `id`, `nick`, `displayName` и `avatar` (из профиля), `createdAt`. Вход по `nick` + пароль → токен сессии (хранить в `expo-secure-store`, не в AsyncStorage).
- **Проверка ника**: «свободен?» + до 3 свободных вариантов.
- **Поиск**: по префиксу ника (от 3 знаков, до 10), без заблокированных в обе стороны.
- **Дружба и заявки**: входящие / исходящие (`id`, кто, когда, `seen`), принять / отклонить / отменить; список друзей с `since`.
- **Открытое дерево друга** (только `visibility = 'friends'`): `id`, `lineageId`, `name`, `nickname`, `kind`, `skin`, `plantedOn`, `checkins` (все или за последние 400 дней — для серии и недели), `frozen`, `chancesLeft`, `diedOn`, `completedOn`, `generation`, клетка участка; плюс `plot.size`, `hiddenCount`, `lastSyncAt`, «обычное время полива» (медиана за 14 дней — для «ждём · вечером»).
- **Поддержка**: `from`, `to`, `day`, `at`; сервер не даёт отправить вторую за день одному человеку.
- **Общее дерево**: `id`, двое, `habitName`, `kind`, `skin`, `plantedOn`, `generation`, поливы каждого (дата по его календарю), `state` (`proposed` / `growing` / `dead` / `stopped`); предложить / принять / отклонить / отменить / выйти.
- **Жалоба**: на пользователя или на название дерева: причина, комментарий, кто (сервер не раскрывает).
- **Блокировка**: список, заблокировать / разблокировать.
- **Удаление аккаунта**: стирает всё на сервере.

### 12.2 Что уходит с телефона
Только деревья с пометкой «Друзья» (+ число скрытых). Смена пометки на «Только я» удаляет дерево с сервера. Отправка: после каждого полива / посадки / правки (через 2 с, пачкой) и при запуске. Никаких контактов, почты, телефона.

### 12.3 Хранилище в телефоне (версия 4 — вместе с магазином)
```ts
account: { id: string; nick: string } | null;      // токен — в SecureStore
accountPromptSeen: boolean;                        // экран 3.1-1 показан
friendsCache: { fetchedAt: number; friends: FriendView[]; requests: Requests; cheersIn: Cheer[] } | null;
cheered: Record<FriendId, DayKey>;                 // кого я подбодрил сегодня
seen: { requests: string[]; cheersDay: DayKey | null };
queue: QueuedAction[];                             // { id, kind, payload, createdAt, tries }
shared: SharedTreeLocal[];                         // общие деревья: мои поливы + последнее известное от друга
```

### 12.4 Тесты (чистые функции)
- `nick.ts`: приведение ввода; каждое правило 3.4; зарезервированные.
- `leaders.ts`: «спортивные» места, я первый среди равных, «Неделя» с поколениями и общим деревом, «Серия» только растущих открытых.
- `shared.ts`: день засчитан только при двух поливах; пропуск одного тратит общий шанс; гибель; пополнение 1-го; «ещё считается».
- Очередь: повтор, порядок, дубль не отправляется дважды.

## 17. Что решает архитектор / владелец (с советом)
1. **Пароль без почты не восстановить.** Совет: после создания аккаунта один раз показать **код восстановления** (12 знаков, «Сохрани в заметках») — вход по нику + коду даёт задать новый пароль. Почту не просим. Без этого часть людей навсегда потеряет друзей при смене телефона.
2. **Поиск — по префиксу (с 3 знаков) или только точный ник.** Совет: префикс, до 10 результатов — удобнее; ники и так публичны. Если боимся перебора — только точный.
3. **Домен для ссылки-приглашения и deep link.** Совет: свой домен под новое название; до него в тексте только ник.
4. **Пуш-уведомления** («тебя подбодрили», «заявка», «друг полил общее дерево») — сервер есть, Expo Push можно. Совет: в этой волне не делать, точка в меню и карточки внутри; пуши — отдельной задачей с настройкой «что присылать».
5. **Лидеры считают только открытые деревья.** Совет: да.
6. **Общих деревьев: одно на пару, всего не больше 3 растущих.** Совет: да на старте.
7. **Общее дерево видят другие друзья?** Совет: только двое (в лесу третьих лиц его нет) — проще и приватнее.
8. **Жалобы**: кто и где их разбирает (на домашнем сервере нужна хотя бы страница-список для владельца). Обязательно до публикации.
9. **Возраст 13+ и согласие на обработку данных** (152-ФЗ, GDPR — привычки бывают «о здоровье»): текст «Правил» и «Политики» — с юристом; страницы должны открываться до публикации.
10. **Жёлуди за полив половины общего дерева (+5)** — совет: да, как за обычное дерево.
11. **Дерево друга крупно (`friend-tree`)** — совет: если останется время, иначе тап по строке открывает лес друга с выбранным деревом.
