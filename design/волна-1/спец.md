# Волна 1 «Живой главный экран» (v0.6): спецификация

Макет: `design/волна-1/макет.html` (открыть через локальный сервер: `python -m http.server` в папке `design/волна-1`, затем `/макет.html`. Режимы: `?grid` — лист всех кадров, `?f=01` … `?f=14` — один кадр 375×812). Снимки лежат в `design/волна-1/кадры/`, общий лист — `кадры/все.png`.
Деревья в макете вырезаны из снимка v0.5 и подкрашены фильтрами. В приложении они будут нарисованы настоящим Skia, поэтому цвета «неполитого» и ночного дерева смотреть по формулам ниже, а не по макету.

## 0. Коротко

Главный экран становится **окном в живой мир**:
- **Небо:** плывут облака в три слоя. Днём солнце медленно вращает лучами, изредка пролетает стайка птиц. Ночью луна с ореолом, звёзды мерцают, иногда падает звезда.
- **Земля:** вместо клочка холма — просторный луг до горизонта. За ним в дымке голубые горы, зелёные холмы и полоска дальнего леса. Трава качается на ветру, ночью над ней летают светлячки.
- **Соседи:** деревья других привычек стоят на лугу **по дуге**. Текущее дерево впереди и большое, соседи — сзади слева и справа, маленькие. Свайп ведёт деревья по этой дуге: соседнее выходит вперёд, текущее уходит назад. Слои неба и холмов сдвигаются с разной скоростью (параллакс), поэтому кажется, что едет камера.
- **Полив:** неполитое дерево поникло и выцвело, земля у корней сухая и в трещинах, над кроной покачивается пузырь с каплей. Нажатие запускает полив: лейка, струйка капель, земля темнеет, дерево распрямляется и наливается цветом. Жетон «+1» улетает в счётчик колец, и счётчик перещёлкивается. Ничего не остаётся висеть на экране.
- **Новая стадия:** сцена темнеет, к дереву стекаются огоньки, потом вспышка, лучи, облако листьев, старая стадия превращается в новую, выпрыгивает золотая лента «Новая стадия — Деревце». Около 3 секунд, вибрация нарастает. Тап пропускает.
- **Без анимаций** всё стоит неподвижно, но красиво, а неполитое дерево всё равно отличается от политого.

## 1. Правила, которые держат весь экран

| Правило | Число |
|---|---|
| Живых холстов Skia на главном экране | **3**: небо (А), луг (В), живое дерево (Б). В пустом состоянии вместо дерева холст лунки. Во время праздника новых холстов не появляется |
| Соседние деревья | картинки `TreeThumb` (снимок в памяти), а не холсты |
| Перерисовка React во время анимаций | нет. Всё движение идёт через shared values Reanimated, Skia читает их напрямую |
| Частиц одновременно | не больше 60 (полив ~20, праздник ~45, светлячки 8) |
| Общие часы | один `useFrameCallback` в `useWind` (А) даёт время `t` в секундах. Небо, трава, дерево и соседи берут фазу из него, поэтому ветер везде один |
| Анимации выключены | `settings.animations === false` **или** системное «Уменьшить движение» (`useReducedMotion()` из Reanimated). Что именно происходит — в разделе 11 |
| Кривые | приход — замедление в конце (`Easing.out(Easing.cubic)`), уход — ускорение (`Easing.in(Easing.cubic)`). Бесконечные медленные движения (лучи, облака) — линейные или синусоида. Касания и прилёты — пружины `withSpring` |
| Уход быстрее прихода | исчезновения 160–300 мс, появления 200–450 мс |

## 2. Геометрия сцены

Сцена — это всё, что выше нижней плашки. Её высота `H` = верх плашки (В меряет через `onLayout`, не хардкодит). Для экрана 375×812 сейчас `H ≈ 545`.

| Величина | Формула | 375×812 |
|---|---|---|
| `horizonY`, где луг встречает холмы | `round(H × 0.66)`, но не выше `headerBottom + 110` | 360 |
| `feetY`, где стоит переднее дерево | `H − 38` | 507 |
| `backFeetY`, где стоят соседи в 1 шаге | `horizonY + 30` | 390 |
| `headerBottom`, низ шапки (счётчик + имя) | меряется | ~180 |
| `topInset` | safe area | 47 на iPhone 14 |
| Центр солнца/луны | `x = 44`, `y = topInset + 30` | (44, 77) |

Размер переднего дерева (Б). Масштаб рисунка `k = min(W × 0.86 / 300, (feetY − headerBottom − 12) / (0.95 × 308))`. Так большое дерево никогда не залезает на шапку, и на маленьких экранах тоже.

### Дуга, по которой стоят деревья (общая функция `slotAt`)

`d` — сколько привычек между деревом и камерой (дробное, со знаком: минус — слева). `a = |d|`. Значения между ключевыми точками интерполируются линейно; после `a = 3` дерево не рисуется.

| `a` | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| сдвиг по x от центра (доля W, со знаком `d`) | 0 | 0.34 | 0.47 | 0.56 |
| y ног | `feetY` | `backFeetY` | `horizonY + 16` | `horizonY + 8` |
| масштаб | 1 | 0.36 | 0.26 | 0.20 |
| непрозрачность | 1 | 1 | 0.9 (при 2.6 — 0.5) | 0 |
| дымка (подмес цвета горизонта) | 0 | 0.16 | 0.28 | 0.40 |

- Минимальная видимая высота соседа — 28 px: крошечный росток сзади масштаб не уменьшает ниже этого.
- Порядок рисования: дальние раньше, ближние позже, живое дерево всегда сверху.
- Эта же функция ставит и живое дерево (Б), и картинки соседей (В). Поэтому при проезде они движутся одинаково, и в момент подмены картинки на живое дерево ничего не прыгает.

### «Жажда» дерева — цветовой фильтр (Б)
Дуб берёт цвета из палитры, а сакура и ёлка — свои, поэтому палитру не подменяем. Вместо этого кладём на группу дерева **цветовую матрицу** (`<ColorMatrix>` в `layer` группы), и она одинаково работает для всех видов. Насыщенность 0.55, тёплый сдвиг:

```
R: 0.6457 0.3218 0.0325 0  +0.035
G: 0.0957 0.8718 0.0325 0  +0.020
B: 0.0957 0.3218 0.5825 0  −0.030
A: 0      0      0      1   0
```
Сдвиги даны в долях 0..1. Если в Skia 2.14 сдвиг ждёт значения 0..255, их нужно умножить на 255 и проверить на глаз по кадру 1 макета. Во время полива матрица плавно переходит в единичную: `M(s) = lerp(I, Dry, thirst)`, где `thirst` — shared value от 1 до 0. `TreeThumb` с `thirsty` рисует снимок с той же матрицей.

## 5. Небо (разработчик А)

### 5.1 Градиент
Вертикальный, 3 точки (верх, 60 %, горизонт), до `horizonY + 10`. Смена дня и ночи: внутренний `nightness` (0..1) идёт `withTiming` 900 мс `Easing.inOut(Easing.cubic)`, цвета интерполируются (`interpolateColor`). Звёзды проявляются с 0.4 до 1.0 `nightness`.

### 5.2 Солнце (день)
- Центр — раздел 2. Ядро r 19 (радиальный градиент, блик смещён к (−0.1, −0.12)). Ореол r 66. 12 лучей: отрезки от r 26 до r 35, толщина 4, круглые концы.
- Лучи вращаются: 360° за **60 с**, линейно, бесконечно.
- Ореол «дышит»: масштаб 1 → 1.08 → 1, период **4 с**, синусоида.
- Смена на ночь: солнце опускается на +60 px и гаснет за 900 мс, луна поднимается с +60 px.
- Тап по солнцу или луне (зона 56×56) переключает тему, как сейчас иконка. Иконку `SunMoon` на главном экране убираем, на её месте теперь настоящее солнце (В делает прозрачную кнопку).

### 5.3 Луна (ночь)
Диск r 18, три кратера (r 4, 3, 1.8), ореол r 62 «дышит» прозрачностью 0.85 ↔ 1.0, период 6 с.

### 5.4 Звёзды (ночь)
- 46 точек (r 0.7–1.7, α 0.35–0.95) и 14 четырёхлучевых искр (размер 2.4–5.6, `#FFE39A`). Разбросаны в полосе y 30 … `horizonY − 40`, по сиду, чтобы каждый раз одинаково.
- Мерцание без отдельной анимации на каждую звезду: звёзды делятся на 3 группы с периодами **3.1 / 4.3 / 5.7 с**, `α = base × (0.6 + 0.4 × sin(2πt/T + φ))`. Искры заодно чуть меняют размер, 0.9–1.1.
- Падающая звезда: раз в **30–60 с** (случайно). След 90 px (градиент белый → прозрачный), голова r 1.6, наклон вниз-влево 20–30°, **650 мс**, `Easing.in(quad)`. Только ночью и только если анимации включены.

### 5.5 Облака
Форма — кодом: 4 круга и скруглённая полоса снизу, сверху блик-дуга, снизу плоская тень. Каждая форма один раз записывается в `SkPicture`, дальше в кадре её только двигаем.

| Слой | Штук | Масштаб | α день/ночь | Скорость | Параллакс (px за 1 привычку) | Полоса по y |
|---|---|---|---|---|---|---|
| дальний | 4 | 0.45–0.55 | 0.6 / 0.45 | 4 px/с | 0.03 W | 0.30–0.48 H |
| средний | 3 | 0.75–0.85 | 0.85 / 0.6 | 7 px/с | 0.07 W | 0.36–0.52 H |
| ближний | 2 | 1.0–1.1 | 0.95 / 0.7 | 11 px/с | 0.10 W | 0.38–0.50 H |

- Облака плывут вправо и по кругу переходят через край: ширина поля `W + 240`, позиция берётся по модулю.
- В порыв ветра скорость × 1.3.
- Над шапкой облака не ставим: верхняя граница полосы не выше `headerBottom + 8`.

### 5.6 Птицы (день)
- Первая стайка — через **4 с** после открытия экрана (чтобы её заметили), дальше раз в **18–40 с**.
- 3–5 птиц, галочки размахом 10–14 px. Летят с одного края на другой за **7–9 с**. Путь: `y = y0 + 10·sin(2π·p·1.5)`, где `y0` случайный в полосе 0.25–0.42 H, у каждой птицы своё смещение ±16 px.
- Взмах — переход формы крыла «вверх ↔ вниз» (`usePathInterpolation`), период 0.32–0.40 с. Иногда планирует 0.8 с без взмахов.
- Во время праздника и полива новые стайки не запускаются.
- Ночью птиц нет: вместо них светлячки на лугу (В).

### 5.7 Ветер (`useWind`)
- Возвращает `{ t, gust }`: `t` — секунды с открытия экрана; `gust` — сила от 0 до 1, базовая 0.25.
- Порыв раз в **6–12 с**: подъём **0.8 с** (синусоида) до 0.6–1.0, держится 0.5 с, спад **1.8 с**.
- Анимации выключены — `t` стоит на 0, `gust = 0`.
- Расписание порывов — чистая функция от сида и времени, её можно покрыть тестом.

## 6. Луг и земля (разработчик В)

### 6.1 Горы, холмы, лес
- Силуэты строятся кодом как сумма синусоид. Периоды подобраны так, что силуэт **повторяется ровно через 2048 px** (каждый период делит 2048 нацело), поэтому он бесшовный при любом числе привычек.
- Дальние горы: основание `horizonY − 8`, амплитуды 58/26/12, периоды 256/128/64. Параллакс 0.04 W за привычку.
- Средние холмы: основание `horizonY + 2`, амплитуды 30/14/6, периоды 512/128/32. Параллакс 0.08 W.
- Полоса леса: зубчики шириной 7 px, высотой 5–11 px, по линии горизонта. Параллакс 0.11 W.
- Дальние кусты: 7 «облачков» из трёх кругов, масштаб 0.7–1.3, на `horizonY + 6`. Параллакс 0.14 W. Цвет специально блёклый, чтобы кусты не путали с деревьями привычек.

### 6.2 Луг
- Градиент от `horizonY` до низа экрана (уходит под плашку), над горизонтом полоса дымки 32 px.
- Три ряда травы. Каждый ряд — одна `SkPicture` шириной 760 px, рисуется дважды встык.

| Ряд | Полоса по y | Высота пучка | Пучков на 760 px | α | Параллакс | Цветов |
|---|---|---|---|---|---|---|
| задний | `horizon + 8 … +46` | 3–5 | 26 | 0.55 | 0.14 W | 25 %, r 1.3 |
| средний | `+46 … +110` | 5–9 | 22 | 0.75 | 0.25 W | 25 %, r 2 |
| передний | `+110 … H + 6` | 9–15 | 16 | 0.95 | 0.42 W | 45 %, r 3 |

- Трава качается так: каждый ряд наклоняется `skewX` вокруг своей нижней линии, угол `(0.04 + 0.10·gust)·sin(2πt/2.2 + ряд·0.4)` радиан.

## 7. Соседние деревья и проезд камеры (разработчик В)

### 7.1 Что на поле
- Камера `cameraX` — shared value в «привычках» (0 … N−1, дробное).
- `liveIndex` (React state) — у какой привычки живое дерево. Меняется только когда камера остановилась.
- `focusIndex` (React state) = `round(cameraX)` — чья шапка и плашка показаны. Обновляется через `runOnJS`/`scheduleOnRN` только когда меняется.
- Монтируются соседи с `|i − liveIndex| ≤ 3`. Каждый — `Animated.Image`. Стиль из `slotAt(i − cameraX)`: `left`, `top` (ноги на `feetY`), `transform: [{ scale }]`, `opacity`.
- Дымка: поверх картинки та же картинка с `tintColor` = цвет горизонта и `opacity = haze`. Так дальние деревья выглядят дальними.
- Соседи качаются на ветру, дёшево: `rotate` вокруг низа (`transformOrigin: 'bottom'`), угол `0.5° × (0.4 + 1.2·gust) × sin(2πt/3.4 + i)`.
- Неполитые соседи показаны неполитыми: `TreeThumb thirsty`. По полю сразу видно, что ещё осталось полить сегодня.
- Погибшие соседи — серый ствол (как сейчас в лесу), без дымки сверх обычной.

### 7.2 Жест
- Gesture Handler: `Gesture.Pan().activeOffsetX([-12, 12]).failOffsetY([-14, 14])` на всю сцену.
- Тап по дереву ловит Б своим `Gesture.Tap().maxDistance(10)`: если палец уехал, тап отменяется и работает свайп.
- Палец ведёт камеру: `cameraX = start − dx / 300` (300 px пальца = одна привычка, `0.8·W`).
- Края — резинка: за 0 и за N−1 смещение `R(x) = 0.25 × (1 − 1/(1 + 2x))`, то есть максимум четверть привычки.
- Отпускание:
  - `projected = cameraX − 0.2 × vx / 300`;
  - `target = round(projected)`, но не дальше ±1 от стартовой привычки и в пределах 0 … N−1;
  - `withSpring(target, { damping: 22, stiffness: 180, mass: 1, velocity: −vx / 300 })` — доезд 450–600 мс с едва заметным перелётом (< 2 %).
- Точки сверху: `withTiming(target, { duration: min(450 + 150 × (|Δ| − 1), 900), easing: Easing.bezier(0.45, 0, 0.2, 1) })` — плавный «наезд камеры» и через несколько привычек.
- Вибрация: `Haptics.selectionAsync()` в момент, когда `round(cameraX)` сменился (щелчок-«фиксатор»), не чаще раза на привычку.
- Пока Б сообщает `busy` (полив или праздник), свайп выключен (`.enabled(!busy)`), точки тоже не реагируют.

### 7.3 Шапка и плашка при проезде
- `f = cameraX − round(cameraX)` (от −0.5 до 0.5). Шапка и сердечки: `opacity = 1 − 2|f|`, `translateX = −f × 40`.
- Текст шапки и плашки меняется в середине пути, когда шапка невидима.
- Содержимое плашки при смене появляется за 180 мс прозрачностью (плашку целиком не трогаем — она во волне 2).

### 7.4 Подмена картинки на живое дерево
Когда камера встала на новой привычке:
1. Картинка нового дерева уже стоит в центре.
2. `liveIndex` меняется, `LiveTree` монтируется невидимым.
3. После первого кадра `LiveTree` вызывает `onReady`, и картинка гаснет за 120 мс.
4. Старое живое дерево к этому моменту стоит в позиции соседа (`slotAt(±1)`), там же появляется его картинка. Глаз подмены не видит.

### 7.5 Точки привычек
- Активная — «таблетка» 18×8.
- Остальные 8×8:
  - полита сегодня или погибла — заливка `text` α 0.38;
  - ждёт полива — пустое кольцо 1.6 px α 0.55.
- Расстояние 7 px. Зона касания каждой точки ≥ 44×44 (`hitSlop`).
- Подпись для чтения с экрана: имя привычки + «ждёт полива» / «полито».

### 7.6 Одна привычка
Соседей нет: остаются луг, кусты и холмы. Свайп даёт только резинку (максимум 0.25 W) и пружиной возвращается. Точек нет.

## 8. Живое дерево (разработчик Б)

### 8.1 Как рисуется
- Внутри холста сцены — группа с трансформом: перенос к ногам по `slotAt(depth)`, затем `scale`, затем наклон ветра `skewX` вокруг ног.
- Само дерево — существующий `TreeScene` (дуб, сакура, ёлка, стадии без изменений).
- Если на дешёвом Android меньше 55 кадров/с — записать дерево в `SkPicture` (`drawAsPicture`, как в `TreeThumb`) и в кадре рисовать только картинку.
- Ветер:
  - угол `α = A·sin(2πt/T + φ) + 1.2°·gust`;
  - `A = (0.5° + 1.6°·gust) × k`, где `k` зависит от стадии: росток 1.4, сеянец 1.3, кустик 1.1, деревце 1.0, дерево 0.8, большое 0.65;
  - `T` = 2.4 с у ростка и сеянца, 3.2 с у остальных; `φ` из сида дерева.
- Дополнительно крона чуть «дышит»: `scaleX = 1 + 0.008·sin(2πt/1.1)`. Можно не делать, если упирается в производительность.

### 8.2 Неполитое (сегодня ещё не нажимали)
Видно сразу, даже без анимаций:
1. **Цвет:** матрица жажды (раздел 4), `thirst = 1`.
2. **Поза:** `scaleY 0.955`, `scaleX 1.02` от ног, наклон −1.5°. Дерево «осело».
   - Уровень 2 (если хватит времени): `SkinProps.thirst` (0..1). У ростка, сеянца и кустика листья опускаются, угол листа доворачивается к висящему на 25° × thirst. У кроны круги-«облака» оседают на 3 ед. × thirst.
3. **Ветер тяжелее:** `A × 0.6`, `T × 1.2`.
4. **Земля:** сухая лунка с трещинами, 2 опавших листика (у сакуры — выцветшие лепестки `#E3C3CF`, у ёлки ничего).
5. **Пузырь «полей меня»:**
   - белый круг 38 px с каплей 20 px и хвостиком к кроне;
   - стоит над кроной справа: `x = ствол + clamp(ширинаКроны × 0.42, 40, 120)`, `y = верхКроны + 6`, но не выше `headerBottom + 24`;
   - покачивается вверх-вниз на 4 px, период 2.2 с, синусоида;
   - появляется через 600 мс после показа дерева: `scale 0 → 1`, пружина damping 12, stiffness 220;
   - тоже нажимается — это полив.
6. **Плашка** (одна строка в `index.tsx`, делает В): «Дерево ждёт полива — нажми на него» с иконкой капли вместо текущей «Нажми на дерево…». Тексты в i18n добавляет Б.

## 9. Вибрация (`expo-haptics`, только если `settings.vibration` и не web)

| Момент | Вызов |
|---|---|

| Дерево ожило | `notificationAsync(Success)` |
| Жетон долетел, счётчик щёлкнул | `selectionAsync()` |
| Повторное нажатие / закрытый день | `impactAsync(Soft)` |
| Праздник: сбор | `Light` (0), `Light` (150), `Medium` (300 мс) |

## 11. Анимации выключены (или системное «Уменьшить движение»)
- **Небо:** облака стоят на своих местах, лучи солнца не вращаются, ореол без пульса, звёзды не мерцают (у каждой своя постоянная яркость), птиц и падающих звёзд нет.
- **Луг:** трава прямая, светлячки стоят светящимися точками (без мигания).
- **Дерево:** ветра нет. Неполитое по-прежнему поникло, выцвело, с сухой лункой и пузырём (пузырь без покачивания).
- **Полив:**
  - без лейки, капель и жетона;
  - цвет, поза и земля переходят в «полито» за 200 мс прозрачностью (это не движение);
  - число в счётчике меняется сразу, таблетка «+1» показывается 1.2 с и исчезает;
  - вибрация как обычно.
- **Новая стадия:** без затемнения, лучей и частиц. Новое дерево появляется за 200 мс, лента «Новая стадия — …» стоит 2 с (появление и исчезновение прозрачностью по 200 мс) и пропускается тапом.
- **Переключение привычек:**
  - свайп и точки переключают сразу, камера не едет;
  - соседи встают на новые места, смена прозрачностью за 150 мс;
  - слои параллакса стоят на месте, без проезда (от проезда некоторых укачивает).
- **Повторное нажатие:** только таблетка «Сегодня уже полито» и вибрация.

```ts
// app/src/ui/scene/contract.ts — стык волны 1
import type { SharedValue } from 'react-native-reanimated';

/** Размеры сцены (всё выше нижней плашки), в экранных px. */
export interface SceneGeo {
  width: number;
  /** Верх нижней плашки. */
  height: number;
  topInset: number;
  headerBottom: number;
  horizonY: number;
  feetY: number;
  backFeetY: number;
}

export function sceneGeo(width: number, height: number, topInset: number, headerBottom: number): SceneGeo {
  const horizonY = Math.max(Math.round(height * 0.66), headerBottom + 110);
  const feetY = Math.max(height - 38, horizonY + 90);
  return { width, height, topInset, headerBottom, horizonY, feetY, backFeetY: horizonY + 30 };
}

/** Общий ветер: t — секунды, gust — сила порыва 0..1. */
export interface Wind {
  t: SharedValue<number>;
  gust: SharedValue<number>;
}

export interface Slot { x: number; feetY: number; scale: number; opacity: number; haze: number }

const A = [0, 1, 2, 3];
const X = [0, 0.34, 0.47, 0.56];
const S = [1, 0.36, 0.26, 0.2];
const H = [0, 0.16, 0.28, 0.4];

function lerpTable(a: number, xs: number[], ys: number[]): number {
  'worklet';
  if (a <= xs[0]) return ys[0];
  for (let i = 1; i < xs.length; i++) {
    if (a <= xs[i]) return ys[i - 1] + ((ys[i] - ys[i - 1]) * (a - xs[i - 1])) / (xs[i] - xs[i - 1]);
  }
  return ys[ys.length - 1];
}

/** Где стоит дерево, которое на d привычек от камеры (d < 0 — слева). */
export function slotAt(d: number, g: SceneGeo): Slot {
  'worklet';
  const a = Math.min(Math.abs(d), 3);
  const s = d < 0 ? -1 : 1;
  return {
    x: g.width / 2 + s * g.width * lerpTable(a, A, X),
    feetY: lerpTable(a, A, [g.feetY, g.backFeetY, g.horizonY + 16, g.horizonY + 8]),
    scale: lerpTable(a, A, S),
    opacity: lerpTable(a, [0, 1, 2, 2.6, 3], [1, 1, 0.9, 0.5, 0]),
    haze: lerpTable(a, A, H),
  };
}

/** Пикселей пальца на одну привычку. */
export const DRAG_PX = 300;
```

## 15. Как понять, что готово (для тестировщика и критика)
1. Холодный старт днём: через 4 с пролетает стайка, облака плывут, лучи солнца вращаются (заметно за 10 с), дерево качается, в порыв сильнее.
2. Неполитое дерево с первого взгляда отличается от политого (снимки рядом), в том числе с выключенными анимациями.
3. Полив: лейка → капли → мокрая земля → дерево оживает → жетон в счётчике. Через 2.5 с на экране нет ни «+1», ни лейки.
4. Новая стадия (через `+1 день` в DevBar до 3/7/21/50/100): праздник около 3 с, лента с правильным названием, тап пропускает, вибрация на телефоне нарастает.
5. Свайп ведёт деревья за пальцем без задержки; отпускание доезжает пружиной; точки дают плавный проезд через несколько привычек; подмена картинки на живое дерево не мигает.
6. Ночь: луна, мерцание, падающая звезда за минуту ожидания, светлячки.
7. В браузере 375×812 на странице не больше 3 холстов Skia (`document.querySelectorAll('canvas').length`).
8. Дешёвый Android (или «Замедление процессора ×4» в Chrome): не меньше 50 кадров/с в покое, не меньше 40 во время праздника.
9. Состояния: одна привычка (резинка), пусто (лунка), погибшее (без пузыря, не нажимается), прошлое поколение (стрелки, без полива).
