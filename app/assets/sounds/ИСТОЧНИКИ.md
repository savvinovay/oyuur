# Звуки: откуда взяты

Все 15 файлов — **свои**, синтезированы скриптом `app/tools/sounds/make.py` (Python + numpy → WAV → ffmpeg → mp3). Чужих записей и наборов нет, лицензий не нужно.

Пересобрать: из папки `app` — `python tools/sounds/make.py` (нужны numpy и ffmpeg, подробности в начале скрипта). Случайные части с постоянным зерном: каждый запуск даёт те же файлы.

Формат: mp3, моно, 44.1 кГц, 96 кбит/с, пики −3 dBFS, тишина по краям обрезана, атака 5 мс. Все вместе — около 102 КБ.
