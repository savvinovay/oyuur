# Ключ подписи APK для тестеров

`test-debug.keystore` — стандартный открытый тестовый ключ React Native / Expo (тот, которым подписан первый APK 1.0, собранный на компьютере). Пароль `android`, имя `androiddebugkey`. Он не секретный: лежит в каждом новом проекте.

Зачем: Android обновляет приложение поверх только APK с тем же ключом. У друзей-тестеров стоит APK 1.0 с этим ключом, поэтому облачная сборка (`eas.json` → `preview` → `credentialsSource: local`) подписывает им же — новые версии встают поверх, лес сохраняется.

Перед Google Play — перейти на настоящий закрытый ключ со сменой ключа (APK Signature Scheme v3, `apksigner rotate`), задача в Huly (этап 3).
