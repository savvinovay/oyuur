# Как открыть приложение

Код приложения лежит в папке `app/`. Node.js уже установлен.

## На компьютере (в браузере) — для ежедневной проверки

1. Открыть терминал в папке `app`.
2. Один раз (или после обновления зависимостей): `npm install`. С версии 0.5 это обязательно: он ставит движок рисования Skia и кладёт его файл для браузера в `app/public/`.
3. Запустить: `npm run web`
4. Откроется браузер на http://localhost:8081. Приложение показано колонкой размером с телефон.

Остановить — `Ctrl+C` в терминале.

## На Android-телефоне — через Expo Go

1. Поставить на телефон приложение **Expo Go** из Google Play.
2. Телефон и компьютер — в одной Wi-Fi сети.
3. В папке `app`: `npm start`
4. В Expo Go отсканировать QR-код из терминала.

Если телефон не подключается (бывает из-за роутера или брандмауэра Windows): `npx expo start --tunnel`.

## Витрина деревьев (для проверки)

В режиме разработки откройте адрес `/gallery` (в браузере: http://localhost:8081/gallery): все виды деревьев (дуб, сакура, ёлка) во всех стадиях рядом. В версии для магазина её нет.

## Перемотка дней (для проверки)

Настройки → «Для разработчика: перемотка дней». Кнопки +1 / +7 / +30 дней сдвигают дату в приложении — так можно за минуту проверить рост, пропуски и гибель дерева. «Вернуть настоящую дату» — обратно. В версии для магазина этого блока не будет.

## Проверки кода

- `npm test` — тесты правил игры.
- `npm run typecheck` — проверка типов.
- Сервер: `cd server && npm test`.

## APK для Android (для друзей-тестеров)

Два способа, результат одинаковый — файл `.apk`, подписанный ключом Oyuur (`app/credentials/README.md`), встаёт поверх прежних.

**На GitHub**: метка `vX.Y.Z` собирает APK в [Releases](https://github.com/savvinovay/oyuur/releases) (нужны секреты ключа в репозитории).

Облако Expo (EAS) APK для друзей больше не собирает: оно умеет подписать только одним ключом, без смены ключа, и такой APK не встанет поверх.

**На этом компьютере** (3–5 минут после первой сборки): из корня проекта — `bash app/tools/build-apk.sh`. Готовый файл — `app/dist-apk/oyuur-<версия>.apk`.
- Нужны Java 17 и инструменты Android в `C:\Users\1\Android` (`jdk17`, `sdk`, CMake 3.31) — уже установлены.
- Скрипт зеркалит приложение в короткую папку `C:\o\app` (у Windows ограничение на длину путей) и собирает там; первая сборка копирует ~3,5 ГБ.
- Подписывает ключом из `C:\Users\1\Oyuur-keys` (`app/tools/sign-apk.sh`); без ключа сборка останавливается.

Важно: телефон обновляет приложение, только если подпись та же (или со сменой ключа от прежней). Друзьям раздавать только APK, подписанные ключом Oyuur.

## Онлайн-сервер (друзья)

Сервер и веб-версия — https://oyuur.ayaal.savvinov.me (homelab). Выложить новую версию: `cd app && npx expo export -p web`, затем из корня `bash server/deploy.sh`. Для проверки на компьютере — свой сервер (`cd server && DB_PATH=./dev.db PORT=8790 node src/main.js`) и приложение с `EXPO_PUBLIC_SERVER=http://localhost:8790 npm run web`. Аккаунты на боевом сервере для проверок не создавать.

Страница владельца (жалобы) — `/owner` на сервере, например https://oyuur.ayaal.savvinov.me/owner. Включается переменной окружения сервера `OWNER_TOKEN` — длинный случайный ключ (от 16 знаков, например `openssl rand -base64 32`); задаётся в настройках приложения на homelab, в git не кладётся. Без неё страницы нет (404). На странице: вход по ключу (iPhone может запомнить его в «Паролях»), новые и разобранные жалобы, «Отклонить», «Скрыть название», «Заблокировать», а в разобранных — «Вернуть название» и «Разблокировать». Ничего не удаляется. Вход держится до закрытия вкладки, но не дольше 12 часов. Сменить ключ — значит выйти со всех устройств. Для проверки у себя: `cd server && DB_PATH=./dev.db PORT=8790 OWNER_TOKEN=любой-ключ-подлиннее node src/main.js`, затем http://localhost:8790/owner.
