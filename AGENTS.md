# AGENTS.md — для Codex и других агентов

Проект Elevate: мобильный трекер привычек «сад, который растёт вместе с друзьями».

Читай перед работой:
- `CLAUDE.md` — паспорт и решения.
- `ПРОДУКТ.md` — что строим и в каком порядке.
- `СТАТУС.md` — где остановились.

Правила:
- Общение и документы — по-русски, просто.
- Не добавлять функций вне текущего этапа из `ПРОДУКТ.md`.
- Без спроса владельца: никаких публикаций, платных сервисов, аккаунтов, серверов.
- Код — в `app/` (Expo SDK 58 + Expo Router + TypeScript). Правила игры — `app/src/game/`, менять только вместе с тестами.
- Перед «готово»: `npm test` и `npm run typecheck` в `app/`. Как запускать — `КАК-ЗАПУСТИТЬ.md`.
